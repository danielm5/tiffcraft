# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Given a version number MAJOR.MINOR.PATCH, increment the:

    MAJOR version when you make incompatible API changes.
    MINOR version when you add functionality in a backward compatible manner.
    PATCH version when you make backward compatible bug fixes.

## [0.2.0-Unreleased]

### Added

- Code examples for loading and exporting TIFF images.
- `TiffStdOut`: header documentation, a README section, the `tiff_info` app for
  printing metadata and IFD tags, and the `tiffStdOutTest` suite.
- README guidance on which headers are needed and the copy-only consumption
  path (header-only; copy the headers into the project, no build step required).
- CMake consumption improvements: a `TiffCraft::TiffCraft` namespaced target,
  an installable/exportable target with generated `TiffCraftConfig.cmake` and
  `TiffCraftConfigVersion.cmake`, and a `TIFFCRAFT_BUILD_ALL` option (on for
  standalone builds, off when consumed via `FetchContent` or `add_subdirectory`).
- A version-consistency test between the CMake `PROJECT_VERSION` and the header
  version constants (`TiffCraft::version()`).
- YCbCr (`PhotometricInterpretation = 6`) export support: `TiffExporterYCbCr`
  converts Y, Cb and Cr to RGB using `YCbCrCoefficients` and
  `ReferenceBlackWhite`, covering all spec-legal subsampling factors in chunky
  and separate planes, stripped and tiled images, packed and padded planar
  chroma rows, and non-default color tags. `TiffExporterAny` dispatches YCbCr
  images to it, and `TiffStdOut` prints the four YCbCr tag names.
  `YCbCrPositioning` is read but not used.
- 31 synthetic YCbCr test images generated by
  `tests/ycbcr_images/generate_ycbcr.py`, with libtiff-generated PPM ground
  truth, and a TIFF 6.0 Section 21 / Technical Note 2 reference in
  `tests/YCBCR_SUPPORT.md`.

### Changed

- CMake project version bumped to `0.2.0` to match the header version constants.
- Vendored `doctest` upgraded from 2.4.12 to 2.5.0.

### Fixed

- `TestExporter` now compares every TIFF/reference pair instead of returning
  after the first successful comparison.
- `TiffExporter.hpp` includes `TiffImage.hpp` directly instead of the umbrella
  header, making it standalone.
- ODR violations in headers: `inline` on `version()`, `readAt()`, `writeAt()`
  and both `load()` overloads; the `operator<<` overloads moved into
  `namespace TiffCraft` and marked `inline` (they are found via ADL, not in the
  global namespace).
- Crash/hang fixes for malformed TIFF input: a zero-count ASCII entry, a zero
  denominator in RATIONAL/SRATIONAL entries, and cyclic IFD offsets now throw
  instead of reading out of bounds, dividing by zero or looping.
- `readAt()` now throws on short reads instead of silently yielding zero-filled
  data for truncated strips/tiles.
- `takeImage()` moves the image buffer out of the exporter instead of copying it.
- `TiffExporterAny` resets its multi-IFD state per IFD, so later IFDs are no
  longer silently skipped.
- Example `tiff_image` reads `ImageWidth`/`ImageLength` type-agnostically, so
  LONG-typed entries no longer throw.
- `readmeUsageTest` catches exceptions and reports them on stderr instead of
  aborting during IDE test discovery.
- README quick-start snippet fixed (removed undeclared `loadParams` argument;
  fixed `iffExporter` typo).
- `Type::BYTE` entries print as integers instead of raw characters.

## [0.1.0]

### Added

- Initial TiffCraft code for loading TIFF images and exporter for bilevel,
  grayscale, palette-color, and RGB images. Compression is not supported.
- Example `tiff_exporter` program to convert TIFF images to PNG 8-bit format.

### Changed

- Moved all headers to `include/tiffcraft`.
